# Timeline — 연도별 흐름

세 축([제품 개발](../product/) · [AX 전환](../ax/) · [개발 프로세스](../process/))을 시간순으로 이었습니다.
**팀 맥락**은 제 기여가 아니라 그 시기 팀 전체의 변화이고, 그 안에서 제가 한 일은 "나의 관여"로만 적습니다.

| 연도 | 내 커밋 | 한 줄 |
|---|---|---|
| 2022 | 145 | 입사, 채용 사이트 빌더로 시작 |
| 2023 | 1,030 | 지원자 관리 화면 전반과 조건 기반 편집 기능 |
| 2024 | 1,180 | 인재 관리·리포트 개편, 외부 서비스 연동이 본격화 |
| 2025 | 1,195 | 일정·일괄 작업·설정 개편, 릴리즈 담당 시작 |

## 2022 — 시작

- **09 ~ 10** 입사. 첫 기능으로 고객사 **채용 사이트 빌더**(헤더·배너·섹션·푸터 블록 편집)를 만들었다.
- **12** 지원자 분류·필터, 일괄 작업, 멤버 초대 화면.

## 2023 — 지원자 관리 화면 전반

- **01 ~ 02** 채용 리포트, 지원자 분류·필터 개선 / **다국어 지원** 작업, 개인정보 설정.
- **03 ~ 04** 지원자 상세 보기 — 채팅·메일·연락 내역·첨부, 메시지 발송 흐름.
- **05 ~ 06** **조건·카드·패널 기반 편집 화면(플로우 빌더)**, 지원서 화면, 온보딩.
- **07 ~ 08** 평가표, 일정 조율, 첨부 개선.
- **09 ~ 10** 다국어 2차, 지원서 입력 항목·추가 질문 개선.
- **11 ~ 12** 코멘트·면접 관련 기능, 공고 관련 신규 기능.

## 2024 — 인재 관리와 외부 연동

- **01 ~ 02** 바로가기·채용 그룹 필터 / **인재 관리**(후보자를 프로젝트 단위로 관리) 화면.
- **03 ~ 04** 요금제 관련 화면, **지원자 일괄 등록·업로드**.
- **05** **리포트 차트·그래프 개편**.
- **06** **외부 채용 플랫폼 공고 연동**, **사내 추천 채용**, **SSO 로그인**.
- **08 ~ 10** **외부 검사·평판 조회·코딩 테스트 서비스 연동**을 연달아 맡음 / 그룹 면접 일정.
- **11 ~ 12** 지원자 데이터 일괄 처리와 상태 업데이트 오류 안내.
- **나의 관여 (통합)** 다른 사람 작업 브랜치 통합 merge 30회 (2023년 10회에서 증가).

## 2025 — 일정·일괄 작업·설정, 릴리즈 담당

- **03** **일정 관리 개선**(커밋 약 69개).
- **06** 지원서 항목 개선.
- **08** **구독 변경 흐름**, **설정 화면 개편**.
- **09** 코딩 테스트 서비스 연동.
- **11 ~ 12** **일괄 작업 확장**, 데스크톱 앱 플랫폼별 수집 QA 대응, 사용자 행동 분석 도구 도입.
- **12 ~** **릴리즈 항목 담당** 시작 (2026-11까지 56건).
- **나의 관여 (통합)** 다른 사람 작업 브랜치 통합 merge 67회 — 연도 중 가장 많음.
- **팀 맥락** 12월, 프론트엔드 저장소들이 **모노레포로 전환**됨.

## 2026 — 대형 기능, AX, 프로세스

- **02** 로그 관리, 데이터 보관 기간 설정.
- **03** AI 서류 평가 서비스 연동 / 프론트엔드 **데일리 스크럼 체계** 정비.
- **03 ~ 04** **팀 AI 개발 하네스 Codex 이식**(skill 27개), **디자인 근거 검증 게이트** → [AX](../ax/)
- **04** **사용자 비활성화**(커밋 약 72개).
- **05** **서류 요청 개선**(커밋 약 139개).
- **06** **포지션 사용자 정의 보기** / 이 달부터 커밋에 AI 공동 작성이 기본이 됨 (하반기 76%).
- **07** 지원자 상세 뷰·PDF 뷰어, 일괄 선택 인원 정책.
- **08** **칸반 즉시 반영**(범용 구조는 범위 판단으로 보류, 동작별 갱신으로 완료, QA 결함 3건 해결) / **PRD 구조 개선 제안**: 문서 52건 분석, 결정 15건 합의 → [프로세스](../process/)
- **08 ~** 동료 MR 리뷰·승인 80건.
- **09** **PRD 작성·검증 체계** 구현.
- **09 ~ 10** **포지션 모집 상태·접수 예약·둘러보기**(커밋 약 385개, 화면 단위 분담).
- **10** 감사 로그 내보내기 사유.
- **11** **외부 검사 기관 연동** — 구현 전 결정 요청 32건 / 날짜·시간 범위 선택기, 캘린더 종일 일정 표시 / 데스크톱 앱 첨부 링크 수집.
- **팀 맥락** 저장소 이전과 CI 구축, E2E 테스트 도입, 오류 처리 규약 전환이 진행됨.
  **나의 관여**: 오류 처리 규약 전환에 맞춘 백오피스 호환 작업과 규약 문서 보완, 관련 MR 리뷰.
