## 구조

```
timeline/   연도별 → 분기별 주요 작업 한 줄 요약
projects/   대표 프로젝트 카드 (배경 → 접근·결정 → 결과 → 배운 점)
areas/      제품 표면·역량 테마별 인덱스 (프로젝트를 가로로 묶음)
stories/    대화·면접용 짧은 에피소드
data/       월·제품 표면·작업 유형별 커밋 집계 (해시·메시지 없음)
_templates/ 카드 템플릿
```
