# AI 하네스를 다른 런타임으로 옮길 때 먼저 정한 것

- 시기: 2026-03 ~ 04
- 유형: 의사결정 · AX
- 관련 축: [ax](../ax/#1-팀-ai-개발-하네스를-codex로-이식-2026-03--04)

**상황** — 팀은 Claude Code 위에서 돌아가는 공용 AI 개발 하네스(skill·에이전트·훅으로 단계별 개발 흐름을 강제)를 쓰고 있었고,
이를 Codex에서도 쓸 수 있게 옮기는 일을 맡았습니다.

**내가 한 일** — 코드를 옮기기 전에 세 가지를 먼저 정했습니다.
① 같은 저장소 안의 독립 패키지로 둔다, ② 기준(source of truth)은 하나로 두고 매핑 문서로 동기화한다, ③ 1차는 핵심 워크플로만 옮기고 외부 도구 연동·팀 협업 기능은 뒤로 미룬다.
결정과 진행은 세션 단위로 이력 문서에 남겼습니다.
그 위에서 설치·검증 도구, 세션 시작 점검, 단계 상태 관리를 만들고 skill 27개를 옮겼습니다.

**결과** — 약 1주 동안 커밋 7개(파일 114개)로 1차 이식을 마쳤고, 기준 버전이 올라갈 때 두 차례 동기화를 반영했습니다.

**한 줄 요약** — "두 런타임을 맞출 때 기준을 하나로 정하고 범위를 먼저 잘랐습니다. 그래서 핵심 흐름을 빨리 돌리고, 이후 동기화도 문서 기준으로 할 수 있었습니다."
